# AI Quest
Hand-coded static site (HTML/CSS/JS). Build: `python3 tools/build.py` -> output in `aiquest/`.

## Deploy (hosting is fine, site builders are not)
Upload the `aiquest/` folder to GitHub Pages, Netlify Drop or Cloudflare Pages. The URL must open index.html.

## You must do before submitting
1. Replace both PDFs in `aiquest/docs/` with the official completed TSA forms (same filenames).
2. Confirm footer text (school / team ID) and make the GenAI disclosure on Resources accurate.
3. Optional: add Garet font files if you want your outline's exact body font.
4. Judges: Dashboard > Settings > "Teacher preview: unlock all".
